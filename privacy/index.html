Privacy Policy

Last updated: 11 September 2026

Current is a personal macOS finance application that accesses selected Google Sheets in order to display and analyse financial transaction data.

Google user data

Current requests read-only access to Google Sheets using Google OAuth. The application uses this access only to read spreadsheet data that the authorised user has chosen to make available to the application.

How data is used

Google Sheets data is used only to provide the application's finance, transaction-viewing, filtering, reporting and analysis functionality.

Data storage

Financial data is processed locally by the macOS application. OAuth refresh credentials are stored locally using the macOS Keychain. OAuth access tokens are held only as required for authenticated requests.

Data sharing

Current does not sell, rent or share Google user data with third parties. Google user data is not used for advertising.

Data access and revocation

Access is granted through Google OAuth and can be revoked at any time through the user's Google Account permissions.
